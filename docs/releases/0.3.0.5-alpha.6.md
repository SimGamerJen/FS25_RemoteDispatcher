# Remote Dispatcher 0.3.0.5-alpha.6 — Early Public Alpha

This maintenance alpha fixes vehicle-specific loss of Remote Dispatcher keybinds while the player is inside certain vehicles.

## What changed

- Ported the vehicle-input fix now used by HelperProfiles after both mods reproduced the same FS25 binding-loss pattern.
- Corrected the `Vehicle.registerActionEvents` hook contract: its second argument is no longer treated as an `isActiveForInput` boolean.
- Remote Dispatcher now explicitly queries `vehicle:getIsActiveForInput()` before registering in-vehicle controls.
- RD vehicle controls now use `vehicle:addActionEvent(...)` and a per-vehicle action-event table.
- On-foot RD action cleanup now removes only its own stored player action IDs, so it cannot remove vehicle-owned RD action events.
- Retains the alpha.5 localisation fix and passive AutoDrive post-start diagnostics.

## Validation

The corrected input path was tested successfully on the two vehicles previously identified as problematic:

- Zetor Crystal 16045
- Massey Ferguson 8570 harvester

Both behaved correctly across two separate saves, including vehicle entry/exit and normal RD control use.

There are **no intentional changes** to AutoDrive/Courseplay dispatch, distant wake, HelperProfiles worker assignment, persistence or localisation behaviour.

## Controls

- `Ctrl + Alt + D` — toggle target selector.
- `Ctrl + Alt + J` — open Remote Dispatcher Management.
- `-` / `=` — previous/next target while the selector is visible.
- `Ctrl + Alt + R` — start/stop the retained remote target.
- Management `X` — change AutoDrive/Courseplay provider.
- Management `C` — assign HelperProfiles worker.

## Diagnostics

Run `rdStatus` before collecting a log for a Remote Dispatcher issue.

Alpha.6 reports the vehicle-input mode as:

`vehicleAddActionEvent/getIsActiveForInput`

It also retains the passive first-second AutoDrive observer introduced earlier. These diagnostics do not restart or otherwise alter AutoDrive.

## Known alpha limitations

- Single-player only.
- AutoDrive destinations and Courseplay jobs must already be prepared.
- English UI only in the current alpha.
- Broad gamepad/input-remapping, map and vehicle coverage remains beta work.
- Stale persistence records for sold vehicles are ignored rather than automatically pruned.

When reporting an issue, include the relevant `log.txt` and `rdStatus` output.
