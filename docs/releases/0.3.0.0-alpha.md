# Remote Dispatcher 0.3.0.0-alpha.1 — Early Public Alpha

Remote Dispatcher 0.3.0.0-alpha.1 is the first public test release of the cinematic remote-dispatch workflow for Farming Simulator 25.

This is deliberately an **early alpha**. The core workflow has been validated in-game, but broader map, vehicle, input and mod-version coverage is still beta work. Back up important savegames before testing.

## Required companion for this alpha

Install **HelperProfiles 2.1.1.0** alongside Remote Dispatcher before testing or reporting issues:

https://github.com/SimGamerJen/FS25_HelperProfiles/releases/tag/2.1.1.0

HelperProfiles 2.1.1.0 provides Integration API v7, including the scoped preferred-worker contract used by Remote Dispatcher for named-worker dispatch.

## Highlights

- Separate Management GUI and lightweight in-game target selector.
- Remote start/stop of already-prepared AutoDrive and Courseplay jobs without entering the vehicle.
- Distant-vehicle activation so automation can begin without player proximity.
- HelperProfiles 2.1.1.0 named-worker assignment through Integration API v7.
- Fail-closed worker dispatch: a missing, OFF-roster or already-active named worker is rejected rather than silently substituted.
- AUTO worker dispatch continues to follow the normal HelperProfiles/game selection flow.
- Per-save persistence keyed by FS25 vehicle `uniqueId`.
- Automation provider and worker assignment restored after save reload.
- Retained cinematic target restored after a full FS25 restart.
- `rdStatus` diagnostics for support reports.

## Validation completed — 2026-08-30

In-game release-candidate testing confirmed:

- automation and worker assignments survive a full FS25 restart;
- the retained cinematic target is restored correctly;
- named workers are used when available;
- a named worker already active elsewhere is rejected with no silent substitute hire;
- AUTO assignment follows normal HelperProfiles selection;
- Courseplay starts correctly with a Remote Dispatcher-assigned worker;
- AutoDrive remote dispatch remains functional at distance;
- the integration test log was clean of Remote Dispatcher Lua errors, failed persistence operations and HelperProfiles scoped-hire failures.

## Controls

- `Ctrl + Alt + D` — toggle the live target selector.
- `Ctrl + Alt + M` — open Remote Dispatcher Management.
- `-` / `=` — previous/next retained target while the selector is visible.
- `Ctrl + Alt + R` — remotely start or stop the retained target.
- Management `X` — change AutoDrive/Courseplay provider.
- Management `C` — change HelperProfiles worker assignment.

All controls use normal FS25 input actions and can be remapped.

## Known alpha limitations

- Single-player only.
- Remote Dispatcher does not configure AutoDrive destinations or create Courseplay jobs; the automation task must already be prepared.
- AutoDrive/Courseplay compatibility depends on their current runtime interfaces and may require updates when those mods change.
- English UI only for the initial alpha.
- Broad gamepad/input-remapping validation is still outstanding.
- Multi-map and broad vehicle/configuration coverage is still limited.
- Stale per-save records for sold vehicles are ignored rather than automatically pruned.

## Reporting issues

Run `rdStatus` in the developer console and include the relevant `log.txt` when reporting an alpha problem. Please also identify the vehicle, whether the task was AutoDrive or Courseplay, and whether the worker assignment was AUTO or a named HelperProfiles worker.
