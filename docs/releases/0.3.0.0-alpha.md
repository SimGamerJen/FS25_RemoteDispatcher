# Remote Dispatcher 0.3.0.0 — Early Alpha Release Candidate

This release candidate turns the proven cinematic remote-start prototype into a stateful testable alpha.

## Highlights

- Separate Management GUI and lightweight in-game target selector.
- Remote start/stop of prepared AutoDrive and Courseplay jobs without entering the vehicle.
- Distant-vehicle activation so automation can begin without player proximity.
- Optional HelperProfiles API v7 named-worker assignment.
- Per-save persistence keyed by FS25 vehicle unique IDs.
- Retained target restored after save reload.
- `rdStatus` diagnostics for support reports.

## Required testing before public alpha

The remaining release blockers are behavioral validation in FS25, not additional feature work: persistence after a full restart, Courseplay start/stop, AUTO-worker behavior, named-worker rejection, and a clean `log.txt` across the test sequence.
