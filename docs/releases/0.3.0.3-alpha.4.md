# Remote Dispatcher 0.3.0.3-alpha.4 — Early Public Alpha

This is a maintenance alpha for the Remote Dispatcher 0.3 line.

## What changed

- Fixed the GIANTS localisation filename-prefix mismatch. `modDesc.xml` now resolves the shipped English file as `translations/l10n_en.xml`.
- Validation now derives the localisation filename from the `<l10n filenamePrefix=... defaultLanguage=...>` declaration and fails if that GIANTS-resolved path does not exist.
- ZIP validation performs the same resolved-path check against the packaged mod.
- Added passive AutoDrive post-start observation at 250 ms, 500 ms and 1000 ms.
- If AutoDrive drops inactive during the first second after a successful remote start, RD logs the checkpoint, observation time, helper index, destination IDs and remaining wake hold.
- A successful start that remains active through 1000 ms emits one stability line.
- The observer never restarts AutoDrive and never changes the job.

There are **no intentional changes** to the validated AutoDrive/Courseplay start or stop interfaces, distant-wake behaviour, HelperProfiles scoped-hire integration, selector, vehicle input context or persistence.

## Controls

- `Ctrl + Alt + D` — toggle target selector.
- `Ctrl + Alt + J` — open Remote Dispatcher Management.
- `-` / `=` — previous/next target while the selector is visible.
- `Ctrl + Alt + R` — start/stop the retained remote target.
- Management `X` — change AutoDrive/Courseplay provider.
- Management `C` — assign HelperProfiles worker.

The live selector, cycling and remote-dispatch controls work both on foot and while controlling another vehicle.

## Diagnostics

Run `rdStatus` before collecting a log for a Remote Dispatcher issue.

For transient AutoDrive starts, look for either:

- `AD post-start observation ... inactive by ...` — AutoDrive became inactive during the first second after RD successfully requested the start; or
- `AD post-start observation ... active through 1000ms` — AutoDrive remained active through the observation window.

These messages are observational only.

## Known alpha limitations

- Single-player only.
- AutoDrive destinations and Courseplay jobs must already be prepared.
- English UI only in the current alpha.
- Broad gamepad/input-remapping, map and vehicle coverage remains beta work.
- Stale persistence records for sold vehicles are ignored rather than automatically pruned.

When reporting an issue, include the relevant `log.txt` and `rdStatus` output.
