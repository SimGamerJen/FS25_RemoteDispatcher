# Remote Dispatcher 0.3.0.4-alpha.5 — Early Public Alpha

This maintenance alpha fixes the localisation loading regression seen in 0.3.0.3-alpha.4.

## What changed

- Moved Remote Dispatcher localisation to `l10n/l10n_en.xml`.
- Changed `modDesc.xml` to use the proven GIANTS convention `<l10n filenamePrefix="l10n/l10n"/>`.
- Removed the obsolete `translations/l10n_en.xml` path.
- Validation now checks the expected `filenamePrefix + _en.xml` file in both the source tree and packaged ZIP.
- Validation also verifies all Remote Dispatcher input-action and Management UI localisation keys.
- The new layout has been smoke-tested in FS25: the Management title, headers, column labels and buttons render correctly.
- Passive AutoDrive post-start diagnostics introduced in 0.3.0.3 remain unchanged.

There are **no intentional changes** to AutoDrive/Courseplay start or stop interfaces, distant-wake behaviour, HelperProfiles scoped-hire integration, selector, vehicle-input context or persistence.

## Supported companion

Install **HelperProfiles 2.1.1.0** alongside this alpha. It provides Integration API v7 for scoped named-worker dispatch.

https://github.com/SimGamerJen/FS25_HelperProfiles/releases/tag/2.1.1.0

## Controls

- `Ctrl + Alt + D` — toggle target selector.
- `Ctrl + Alt + J` — open Remote Dispatcher Management.
- `-` / `=` — previous/next target while the selector is visible.
- `Ctrl + Alt + R` — start/stop the retained remote target.
- Management `X` — change AutoDrive/Courseplay provider.
- Management `C` — assign HelperProfiles worker.

The live selector, cycling and remote-dispatch controls work both on foot and while controlling another vehicle.

## Diagnostics

Run `rdStatus` before collecting a log for a Remote Dispatcher issue.

For transient AutoDrive starts, alpha.5 retains the passive first-second observer introduced in alpha.4. It will log either an early inactive checkpoint or a successful `active through 1000ms` line. These diagnostics do not restart or otherwise alter AutoDrive.

## Known alpha limitations

- Single-player only.
- AutoDrive destinations and Courseplay jobs must already be prepared.
- English UI only in the current alpha.
- Broad gamepad/input-remapping, map and vehicle coverage remains beta work.
- Stale persistence records for sold vehicles are ignored rather than automatically pruned.

When reporting an issue, include the relevant `log.txt` and `rdStatus` output.
