# Remote Dispatcher 0.3.0.1-alpha.2 — Early Public Alpha

This alpha fixes the input-context limitation found in 0.3.0.0-alpha.1.

## What changed

- Remote Dispatcher live actions are now available both on foot and while controlling another vehicle.
- `Ctrl + Alt + D` can open the target selector while driving.
- `-` / `=` can cycle the retained target while driving.
- `Ctrl + Alt + R` can start or stop another prepared vehicle while the player remains in their current vehicle.
- Management can be opened from the vehicle context.
- The default Management shortcut is now `Ctrl + Alt + J`, avoiding AutoDrive's `Ctrl + Alt + M` notification-history binding.

## Validation

The vehicle-context workflow was tested in-game before release: while driving one vehicle, the selector opened correctly, target cycling worked, another prepared vehicle could be remotely dispatched with its configured worker, and Management opened from the cab.

All previously validated 0.3.0.0 functionality remains in place, including per-save persistence, retained-target restoration, distant vehicle wake-up, AutoDrive and Courseplay dispatch, HelperProfiles named-worker assignment, AUTO worker selection, and fail-closed handling when an assigned worker is unavailable.

## Required companion

Install **HelperProfiles 2.1.1.0** alongside this alpha. It provides Integration API v7 for scoped named-worker dispatch.

https://github.com/SimGamerJen/FS25_HelperProfiles/releases/tag/2.1.1.0

## Controls

- `Ctrl + Alt + D` — toggle target selector.
- `Ctrl + Alt + J` — open Remote Dispatcher Management.
- `-` / `=` — previous/next target while the selector is visible.
- `Ctrl + Alt + R` — start/stop the retained remote target.
- Management `X` — change AutoDrive/Courseplay provider.
- Management `C` — assign HelperProfiles worker.

## Known alpha limitations

- Single-player only.
- AutoDrive destinations and Courseplay jobs must already be prepared.
- English UI only in the current alpha.
- Broad gamepad/input-remapping, map and vehicle coverage remains beta work.
- Stale persistence records for sold vehicles are ignored rather than automatically pruned.

When reporting an issue, run `rdStatus` and include the relevant `log.txt`.
